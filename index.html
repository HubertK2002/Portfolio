O mnieAbout me

Piszę głównie w PHP (Symfony, Laravel) i C++, a po JavaScript/TypeScript, Pythona czy Javę sięgam, gdy pasują do zadania — dobieram narzędzie do problemu, nie odwrotnie. Komercyjnie rozwijałem i utrzymywałem systemy produkcyjne dla realnych klientów: migrację dużej aplikacji z Delphi do C#, autorski system wysyłki SMS z kolejkami, REST API oraz optymalizacje wydajności baz danych. Zależy mi na porządnej architekturze, czystym kodzie i rozwiązaniach, które po prostu działają — od baz danych i integracji, po wdrożenia i konfigurację serwerów. Nie boję się też frontendu (React) ani grafiki 3D w C++. Obecnie kończę studia inżynierskie (Informatyka Stosowana, Politechnika Warszawska).

I mostly write PHP (Symfony, Laravel) and C++, and reach for JavaScript/TypeScript, Python or Java when they fit the task — I pick the tool for the problem, not the other way around. Commercially I've built and maintained production systems for real clients: a large Delphi-to-C# app migration, a custom SMS-sending system with queues, REST APIs and database performance optimizations. I care about solid architecture, clean code and solutions that simply work — from databases and integrations to deployments and server configuration. I'm also comfortable with the frontend (React) and 3D graphics in C++. Currently finishing my engineering degree (Applied Computer Science, Warsaw University of Technology).
